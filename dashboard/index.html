Why 1D-CNN + BiLSTM Hybrid Architecture?

The theoretical synergy of spatial and temporal deep learning

1. Spatial Feature Extraction (1D-CNN): Traditional machine learning relies strictly on engineered statistical summaries. The 1D-CNN scans raw packet bytes like an n-gram scanner, detecting contiguous header patterns (e.g., TCP flag combinations, payload magic bytes, shellcode headers) regardless of their specific offset.

2. Bidirectional Temporal Memory (BiLSTM): Network flows possess chronological and structural dependencies. The BiLSTM processes the feature sequence in both forward and backward directions, recognizing protocol state progressions (such as TCP handshakes, payload entropy transitions, or request-response anomalies).

3. Resilience to Polymorphic Attacks: By combining spatial convolutional filters with sequential memory, the model detects obfuscated or fragmented attacks that bypass simple signature matching.
