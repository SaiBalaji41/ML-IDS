Representation matters

The supplied CICIoT2023 dataset contains 46 tabular flow features. These support the running flow classifier. Raw payload bytes need separately labeled packet data and a separately trained model. They cannot be substituted for flow features.

python scripts/train_packet_bytes.py --manifest data/packet_manifest.csv --benign-label BenignTraffic

Manifest columns: path, label, split (train / validation / test). Each PCAP must contain traffic with a verified label; captures are split by source file.
